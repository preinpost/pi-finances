# Timing (매수/매도 타점 분석)

가격·차트 기반 기술적 분석으로 진입/청산 타점을 판단하는 파이프라인.
**결론은 모델이 내리되, 지표 계산은 반드시 `kis_technical` 도구로** 한다 (직접 계산 금지 — 오류 발생).

## 0. 실행 시퀀스

```
차트·지표 수집(kis_technical) → 4층 판단(추세/모멘텀/밸류교차/리스크)
→ 결론(매수/매도/관망 + 진입가·목표가·손절가·포지션 크기) → 리포트
```

## 1. 데이터 수집

```jsonc
// kis_technical (차트 자동 조회 + 지표 계산)
{ "symb": "005930", "market": "domestic", "period": "D" }   // 국내 일봉
{ "symb": "RKLB",  "market": "overseas", "period": "D", "excd": "NAS" } // 해외
```

- `period`: D=일봉(기본)/W=주봉/M=월봉
- **한계**: 국내 최대 100봉, 해외 최대 100행 (주봉이면 100주 = 약 2년)
- **장기 지표**(200일 MA 등) 필요 시: 기간을 나눠 2회 호출(`kis_domestic_chart { date1, date2 }` 등)해 합산
- 종목코드가 틀리면 빈 응답 — `kis_domestic_price`로 유효성 확인

토스증권 키가 있으면 `toss_chart`로도 동일 지표 계산 가능:

```jsonc
// toss_chart (토스 캔들 → 공용 indicators 계산 — kis_technical과 동일 로직)
{ "symbol": "005930", "interval": "1d", "count": 100 }
{ "symbol": "AAPL",  "interval": "1d", "count": 200 }
```

- 토스는 **1d(일봉)/1m(1분봉)만 지원 — 주봉/월봉 없음** (필요 시 일봉을 주/월 단위로 집계)
- 1분봉은 당일 단기 타점(스캘핑)에 활용 가능 — KIS 차트에는 없는 옵션

## 2. 지표 해석

| 지표 | 판단 |
|---|---|
| MA5/20/60 | 정배열(MA5>MA20>MA60)=상승 추세, 역배열=하락 추세 |
| RSI(14) | >70 과매수, <30 과매도, 50 회복 = 강세 전환 |
| ATR(14) | 변동성 척도 — 손절 폭·포지션 크기 산정에 사용 |
| 볼린저(20,2) | 상단 터치=과열, 하단 터치=과매도, 중단 회복=추세 재개 |
| 지지/저항 | 최근 20봉 저점(지지)·고점(저항) — 돌파/이탈 확인 |
| 추세 | 지표 종합 결과 "상승/하락/횡보" |

## 3. 4층 판단

1. **추세층**: MA 정배열 + 고점·저점 상승 구조 → 매수 우위. 역배열 → 매도/관망 우위.
2. **모멘텀층**: RSI 과매도(<30) 회복, 골든크로스(MA5>MA20), 저항 돌파 → 매수 신호. RSI 과매수(>70), 데드크로스, 지지 이탈 → 매도/관망 신호.
3. **밸류 교차층**: `stock-research` 결과(재무·컨센서스)와 결합 — 지표는 좋아도 펀더멘털이 나쁘면 관망, 반대도 동일.
4. **리스크층**: 손절 = 지지선 아래 또는 ATR×1.5~2. 포지션 = 총자산 대비 리스크 1~2% 기준. 분할 매수 권장.

## 4. 결론 규칙

- **매수**: 추세 상승(또는 횡보→상승 전환) + (RSI 과매도 회복 또는 골든크로스) + 지지/밸류 양호
- **매도**: 데드크로스 또는 RSI 과매수 또는 지지선 이탈 (보유 전제)
- **관망**: 위 조건 불충분, 신호 상충, 밸류 교차 불일치
- **실전 주문은 사용자 확인 후에만** (기존 안전 규칙 — `kis_api`/roles/trading.ts)

## 6. 주의

- **과거 지표는 미래 수익을 보장하지 않음** — 참고용으로만
- 장중 데이터는 실시간 변동 — 기준 시각 명시
- **실전 주문은 사용자 확인 후에만** — 자동 주문 금지
- 밸류 교차층은 `stock-research` 스킬과 조합 (이 스킬 단독은 가격 지표 기반)
- 52주 고저 등 장기 기준은 `kis_domestic_price`의 w52/d250 필드와 교차 확인
