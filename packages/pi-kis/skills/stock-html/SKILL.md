# stock-html — 금융 대시보드 HTML Design System

주식 분석 리포트(시세·52주, 기술지표, 펀더멘털, 컨센서스, 타점 판단, 시나리오)를
**금융 애널리틱스 스킨**의 단일 페이지 HTML로 내보내는 디자인 시스템입니다.

**Visual language: 금융 애널리틱스** — cool gray 캔버스(`#F5F6F8`) 위 흰색 카드,
네이비 잉크(`#171A21`), 블루 액센트(`#2B5CFF`), `tabular-nums` 숫자, 카드/그리드/표 중심.
make-html의 "warm ivory + serif + clay" 편집형과 **정반대**입니다.

## When to Apply — READ FIRST

이 디자인 시스템은 **주식/투자 분석 리포트를 HTML로 명시적으로 요청할 때만** 적용합니다.

- ✅ 적용: "리포트 HTML로 만들어줘", "분석 결과 HTML로 내보내줘", "종목 리포트를 HTML 문서로"
  — 단, 대상이 주식·종목·섹터·타점 분석(시세/지표/재무/컨센서스/판단)일 때.
- ❌ 미적용: 단순 질문/요약/조회, 표 하나만 필요한 요청, 다른 형식(Markdown, PPT, DOCX) 지정.
- **make-html과의 구분**: 주식/투자 리포트 맥락이면 `stock-html`, 그 외 문서(아티클·에세이·번역·PRD)는 `make-html`. 대상이 명확하지 않으면 사용자에게 확인한다.
- 에이전트 내부에서 리포트 마크다운을 이미 만들었다면(예: timing/stock-research 스킬 출력), HTML 변환 요청 시 이 디자인 시스템으로 변환한다.

## 코어 원칙

1. **데이터가 먼저** — 장식적 요소보다 수치의 정확성·가독성 우선. 숫자는 `tabular-nums`.
2. **Self-contained** — `<style>` 인라인, 외부 CDN/폰트/JS 없음. 파일 하나로 배포 가능.
3. **신호는 색으로** — 방향(상승/하락), 판정(상회/미스), 리스크를 시맨틱 색으로 즉시 구분. **문서 상단에 색상 범례를 항상 표기** (한국 관례: 상승=빨강, 하락=파랑).
4. **계층 구조** — KPI → 섹션 카드 → 표/차트 → 결론 콜아웃 → 리스크 → 고지. 섹션마다 번호 헤더.

## 컴포넌트 요약

| 컴포넌트 | 용도 |
|---|---|
| 헤더 | 종목명 + 티커 타이틀, 기준일·데이터 소스 배지, 구분선 |
| KPI 카드 그리드 | 현재가·52주 고저·고점/저점대비·시가총액 등 핵심 수치 3~4열 |
| 섹션 카드 | "1️⃣ 시세·52주 위치" 같은 번호 섹션 — 흰 카드(테두리, 라운드 12px) |
| 데이터 표 | 정렬 헤더, 행 구분선, 오른쪽 정렬 tabular-nums, 셀 하이라이트 |
| 판정 배지 | 매수(빨강)/매도(파랑)/관망(회색)/상회(초록)/미스(빨강) |
| 라인차트(스파크라인) | 종가 배열 → 인라인 SVG 폴리라인 (액센트 블루, 최대 120포인트) |
| 시나리오 확률 바 | 시나리오 표에 진행률 바 (베이스=블루/약세=앰버/강한약세=빨강) |
| 결론 콜아웃 | 매수/매도/관망 대형 배지 + 트리거 체크리스트 + 목표가/손절가 |
| 리스크 리스트 | ⚠️ 아이콘 + 항목, 왼쪽 앰버 보더 |
| 푸터 | 고지문 + 생성일 |

컴포넌트별 HTML 스켈레톤·CSS는 `references/design-system.md` 참고.

## 리포트 → HTML 매핑

| 리포트 섹션 (timing/stock-research/sector-research 출력) | HTML 컴포넌트 |
|---|---|
| 시세·52주 위치 (현재가/52주 고저/고점대비/저점대비/시총) | KPI 카드 그리드 + 데이터 표 |
| 핵심 구조 (파라볼릭/추세 설명, ASCII 차트) | 섹션 카드 — ASCII는 `<pre>` 블록, 가능하면 SVG 라인차트로 변환 |
| 기술적 상태 (MA/RSI/ATR/볼린저/지지·저항) | 데이터 표 (지표×기간) + 스파크라인 |
| 펀더멘털 (매출/영업익/컨센서스 YoY) | 데이터 표 + 판정 배지 (상회/미스) |
| 카탈리스트 & 컨센서스 | 리스트 (번호 아이콘) |
| 판단 (4층 종합 → 결론) | 결론 콜아웃 — 결론 배지 + 트리거 체크리스트 + 목표가/손절가 |
| 시나리오 (확률 포함) | 시나리오 표 + 확률 진행률 바 |
| 리스크 | 리스크 리스트 (앰버 보더) |
| 한 줄 요약 | 푸터 위 강조 박스 (라이트 블루 배경) |
| 고지문 | 푸터 |

## 변환 절차

1. **섹션 파싱** — 마크다운 리포트를 번호 섹션(1️⃣~7️⃣ 등)과 푸터 고지로 분리.
2. **컴포넌트 매핑** — 위 매핑 표대로 각 섹션을 컴포넌트로 변환 (표는 HTML `<table>`, 수치는 `tabular-nums`).
3. **스켈레톤 조립** — 헤더 → KPI → 섹션 카드들 → 결론 → 리스크 → 요약 → 푸터 순으로 조립.
4. **저장** — self-contained `.html`로 저장 (기본 `~/reports/{TICKER}_{YYYYMMDD}.html`, 사용자 지정 경로 우선) 후 브라우저로 열도록 안내.

## 규칙 (필수)

- `<style>`는 `<head>`에 인라인. 외부 리소스(폰트 CDN, JS, 이미지 호스팅) 금지.
- 숫자: `font-variant-numeric: tabular-nums`. 통화/단위 표기 통일 ($, %, 억/조).
- 한국 관례 색상: **상승/매수=빨강, 하락/매도=파랑** — 헤더 아래 범례에 명시.
- 반응형: 모바일에서 KPI/표는 1열로. `@media print`에서 카드 그림자·배경색 제거, 흰 배경 (배지·신호 색은 유지 — 색맹 대비).
- 도구 출력 데이터 그대로 변환 — 값을 임의로 계산/변경하지 않는다 (표기 형식만 정리).
- 파일 저장 시 기존 파일 덮어쓰기 전 사용자 확인 (같은 TICKER+날짜).
- 실전 주문 관련 내용이 리포트에 있으면 고지문을 반드시 유지한다.
