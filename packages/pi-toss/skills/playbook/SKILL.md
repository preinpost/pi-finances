# 돌파 매매 플레이북 (Breakout Playbook)

"느낌"이 아니라 "위치"에 베팅한다. 감정은 트리거에 못 이긴다.

## 플레이북 6단계

| 단계 | 규칙 | 예시 (SPCX) |
|---|---|---|
| 1. 종목 선정 | 뉴스·섹터 모멘텀 확인 | AI 인프라/우주 섹터 |
| 2. 위치 분석 | 차트 툴로 저항·지지·ATR·RSI·추세 계산 | 저항 $139.98, ATR ≈ $11 |
| 3. 진입 트리거 | 돌파형: 저항 +2% (기본) / 되돌림형: 지지선 | $143 트리거 + $144 지정가 |
| 4. 손절 | 돌파선(저항) 아래 — 진입 대비 -3% 이내 | $138.5 |
| 5. 익절 | 손익비 1:3 (OCO 브래킷) | $156 |
| 6. 자동화 | 조건주문으로 감정 개입 차단 | 브래킷 WATCHING 확인 |

## 전략 선택 (상황별)

| 상황 | 전략 | 이유 |
|---|---|---|
| 이벤트 직전 (FOMC·실적) | 되돌림 매수 (지지선) | 변동성으로 지지선 테스트 잦음 |
| 강한 모멘텀 확인 | 돌파 매수 (저항 +2%) | 되돌림이 안 옴 |
| 돌파형 사용 시 | 손절 타이트 (-1.5~2%) | 페이크아웃 시 빠른 컷 (기본 -3% 한도보다 타이트) |

## 돌파 트리거 버퍼

| 버퍼 | 걸러지는 것 | 용도 |
|---|---|---|
| +0% (저항 그대로) | 없음 — 첫 터치에 체결 | 페이크아웃 최다. 비추 |
| +1% | 일중 위꼬리(스파이크) 페이크 | 2회 이상 찍힌 견고한 저항 |
| +2% | 하루~이틀짜리 페이크 대부분 | **보편적 기본값** |
| +3% 이상 | 거의 모든 페이크 | 극단 변동성·이벤트 직전 (체결가 ↑) |

- 정교 버전: **트리거 = 저항 + 0.3~0.5 × ATR(14)** — 변동성 큰 종목은 %보다 ATR (SPCX 일 ATR ≈ $11)
- 저항 성격: 2회 이상 찍힌 저항(견고)은 +1~2%면 충분, 1회 찍힌 가격은 +2%

## 이상적 구조 (돌파 매수 세트)

```
트리거(매수): 저항 +2%      예: $143.0
매수 지정가:  트리거 + ~1%  예: $144.0  ← 시장가 체결 슬리피지 고정
손절:         돌파선 아래    예: $138.5  (최대 손실 ≈ -3%)
익절:         1:3            예: $156    (+9%)
```

핵심: **손절은 항상 돌파선(저항) 아래** — 돌파 실패 = 저항 밑 회귀 = 즉시 청산 구조.
이러면 실패 비용이 저렴: 페이크아웃이면 미체결로 0원, 찍고 무너지면 -3% 컷, 성공하면 +9%.

## ⚠️ 돌파 매수 시 유의점

1. **페이크아웃이 최대 적** — 저항 터치 후 되돌림은 가장 흔한 실패 패턴. 조건주문은 가격 "터치"만 감지하므로 위꼬리 스파이크와 진짜 돌파를 구분 못 함 → 트리거 버퍼가 유일한 방어선
2. **거래량 조건 없음** — 진짜 돌파는 거래량 동반이지만 조건주문에는 거래량 조건이 없음. 거래량 확인이 필요하면 수동 진입 판단에만 활용 (트리거 버퍼로 보완)
3. **손절은 "돌파선 아래 + 약간 여유"** — 딱 돌파선 위($140)는 위꼬리 한 번에 튕겨나감. 돌파선 리테스트를 버틸 여유(예: $138.5~139) 필요. 단 여유가 너무 크면 손실이 커짐
4. **체결가 슬리피지** — 트리거 + 시장가 = 급등 시 트리거 위에서 체결 → 예상보다 비싼 진입 (트리거 $143인데 $145 체결). **매수 지정가 병행**으로 최악 체결가 고정
5. **갭 리스크 (조건주문 한계)** — OTO/OCO는 지정가만 허용: 갭 하락 시 손절 미체결(손절이 안 됨), 갭 상승 시 매수 미체결. 이벤트 직전엔 갭 리스크가 커지므로 트리거 상향 or 진입 보류
6. **이벤트 리스크** — FOMC·실적 발표 직전 돌파는 페이크 확률 급증, 발표 후 갭으로 브래킷 왜곡. 이벤트 직전에는 되돌림형 or 관망
7. **추격 금지** — 이미 크게 오른 종목은 R/R 열화로 진입 금지. 버퍼가 높을수록 진입가↑·손절 거리↑ = R/R 악화 → 버퍼는 "충분히"만, 과하게 말 것
8. **자금·비중 관리** — 1회 리스크(손절 금액) = 총자산의 1~2%. 예약주문 전 **매수 가능 현금 확인** (USD/KRW 여력 — toss_balance). 여러 종목 동시 돌파는 섹터 상관관계 주의 (AVGO/DELL 동반 페이크아웃 시 일괄 손절 위험)
9. **손절은 계획이지 감정 아님** — 진입 후 -0.5~1% 되돌림에 청산하면 브래킷의 의미가 없음. 브래킷 발동 전까지 아무것도 하지 않기. 반대로 익절 직전 감정적 홀드는 금지
10. **진입 후 관리** — 돌파 성공 확인 후에만 손절을 진입가 위(손익분기)로 이동. 타이트닝은 이벤트 휩쏘에 튕길 수 있으므로 신중히
11. **기록·반성** — 트리거/지정가/손절/익절/체결가/결과를 기록 → 버퍼와 손절 위치를 다음에 조정 (자기반영)

## 실전 사례 (SPCX, 2026-08)

- 실제로 한 것: 트리거 $140.5 (저항 +0.4%) → 페이크아웃 체결 ($140.52) → 되돌림 -1.2%
- 이상적이었을 것: 트리거 $143 (+2.2%) → 페이크 통과, 미체결로 0원 회피
- 교훈: 저항 직상 트리거는 페이크 최다. 저항 $139.98 기준 +2% = $142.8~143

## 실행 (토스증권)

- 툴 파라미터·타입 규칙(OCO/OTO/secondSide): **toss-conditional 스킬** 참고
- 예약 매수 + 체결 시 위아래 로스/익절 브래킷: toss-conditional 스킬의 패턴 A/B 참고
- 실전 주문은 사용자 확인 후에만 (toss_conditional create/modify/cancel)
- 참고 수치 (2026-08 기준, 재계산 필요): DELL 저항 $485.7 → +2% 트리거 $495.4, 손절 $483~485 / AVGO 저항 $432.7 → +2% 트리거 $441.4, 손절 $430~432
